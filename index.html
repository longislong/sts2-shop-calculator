STS2 ショップ計算機

ショップで「今持っているお金で、何をどこまで買えるか」を素早く計算するためのブラウザツールです。

ショップ画面を見ながら価格を入力し、購入したいものにチェックを入れるだけで、商品合計・残金・割引適用後の価格をリアルタイムで確認できます。

特に、会員カード・配達人によるショップ割引を含めて計算したい場合に便利です。

基本的な使い方

1. 所持金を入力

画面上部の「所持金」に、現在持っているゴールドを入力します。

2. ショップの商品価格を入力

STS2のショップ画面を見ながら、

  • 通常カード
  • 無色カード
  • レリック
  • ポーション

の価格を入力します。

最初は各カテゴリ1枠だけ表示されています。価格を入力すると、そのカテゴリ内に次の入力欄が自動的に追加されます。

ショップの最大枠数に合わせて、

  • 通常カード：最大5枠
  • 無色カード：最大2枠
  • レリック：最大3枠
  • ポーション：最大3枠

まで入力できます。カード削除は1枠固定です。

商品名も変更できます

「通常カード1」「レリック1」などの商品名部分をクリックすると、名前を変更できます。

例えば、

通常カード1 → フットワーク
レリック1 → 剃刀の牙

のように、ショップ画面を見ながら自分で分かりやすい名前を付けられます。

名前を空欄にして確定すると、元の「通常カード1」などの表示に戻ります。

なお、名前の変更はその場限りで、ブラウザには保存されません。

購入する商品をチェック

実際に購入したい商品には、右端の「購入」チェックを入れます。

現在の残金で購入できる商品は、未チェックでもチェックボックスが緑色に強調表示されます。

そのため、「これなら今買える」という商品をショップ画面を見ながら直感的に確認できます。

購入チェックを入れると、その価格が商品合計に加算され、残金もリアルタイムで更新されます。

会員カード・配達人にも対応

ショップで会員カードや配達人を購入する場合は、それぞれの販売価格を入力してチェックします。

入力欄の説明に従って、

会員カードを購入する場合の販売価格
配達人を購入する場合の販売価格

を入力してください。

会員カード＋配達人を同時に購入する場合

会員カードを購入すると、その後に購入する配達人には会員カードの割引が適用されます。

そのため、会員カード → 配達人の購入順を考慮し、配達人の購入価格を自動的に割引して計算します。

また、会員カードと配達人自身には、それぞれの割引を重複して適用するのではなく、割引購入後の商品に対して割引が適用される形で計算されます。

計算結果は常に確認できます

画面上部には、

  • 初期所持金
  • 商品合計
  • 商品合計の内訳
  • 残金

が表示されています。

商品一覧を下へスクロールしても、この計算結果は画面上部に固定されているため、「今いくら残ってる？」を確認するためにいちいち上まで戻る必要がありません。

キーボード入力にも対応

商品価格の入力欄で Tabキー を押すと、購入チェックボックスを飛ばして、次の商品価格入力欄へ移動します。

そのため、

価格入力 → Tab → 価格入力 → Tab → …

と、ショップ画面を見ながら連続して価格を入力できます。

現在の状態をそのままコピー

ページ下部には「現在の状態」というテキストボックスがあります。

ここには現在のショップ状況が自動的に整形されて表示されます。

入力を全部やり直したいとき

画面右上の 「入力を全リセット」 を押すと、現在の入力をすべて初期状態に戻せます。

  • 所持金
  • 商品価格
  • 購入チェック
  • 会員カード・配達人の設定
  • 商品名の変更
  • 増やした商品入力欄

などがまとめてリセットされます。

このツールでやりたいこと

要するに、

「ショップを見ながら、価格を打ち込んで、買いたいものにチェックを入れるだけ。
あとはツールが計算してくれる」

というツールです。

特にSTS2のマルチプレイなどで、

「これ買ったら残りいくら？」
「会員カードを買って割引を得たら、さらに何が買える？」
「この商品とこれを両方買っても大丈夫？」

といった計算を頭の中でする代わりに、ショップ画面の情報をそのまま入力して確認することを目的にしています。

ブラウザ上で動作するため、インストールやアカウント登録などは必要ありません。
